## 1. The game in one paragraph

Every day at midnight Hawaiʻi time, everyone gets the same 5 spots somewhere in Hawaiʻi. For each spot you are dropped into a view of the place. You cannot move. You can only turn and tilt to look around. When you think you know where you are, you open a map of the islands, drop a pin, and lock it in. The closer your pin is to the real spot, the more points you get, up to 5,000 per round and 25,000 per day. After round 5 you see your total, share a spoiler free result, and see how you rank today and this month. No accounts. You just pick a player name. A daily reminder is optional. There is a short tutorial, a practice mode, an about page, and stats.

## 2. Decisions made, and the few left for Olin

Decided in this spec

1. Android app built as a web app inside Capacitor. This is the fastest path to a polished app because the best free map and 360 viewers (MapLibre GL JS and MapillaryJS) are web libraries. It also makes an iOS or web version easy later.
2. Two view types.
   - **Sky view** is satellite imagery seen from above at a tilt, over 3D terrain. You swivel and tilt only. Zoom and position are locked. This is what was asked for.
   - **Ground view** is a street level 360 photo from Mapillary (free, open imagery). You swivel and zoom in a little. You cannot walk.
   The daily set mix is a server setting. Default is 5 Sky rounds. Turn on Ground rounds once the location pool has enough good ones.
3. Same 5 spots for everyone each day, like Wordle. This is what makes a leaderboard fair.
4. The day flips at midnight Hawaiʻi time (HST, UTC minus 10, no daylight saving) for everyone in the world.
5. Backend is Cloudflare Workers plus D1 (SQLite) on the free plan. Cost is $0 per month until roughly 7,000 players a day. Full math in section 5.
6. Notifications are local, scheduled on the phone. No push server, no Firebase, no cost.
7. Names are unique. Filtered on the phone and again on the server.
8. Code license is MIT.

Open decisions for Olin (each has a default so work is never blocked)

| Question | Default if no answer |
|---|---|
| App name. Options are Huli, Aia i Hea? ("where is it?"), Ma Hea | Huli |
| Monthly board. Top 5 players by their single best day, or top 5 by sum of their best 5 days | Single best day. Server flag `MONTH_RANK_MODE` = `best_day` or `best5_sum` |
| Round timer on the daily | 120 seconds per round. Server flag `DAILY_ROUND_SECONDS`, 0 turns it off |
| Include Niʻihau and Kahoʻolawe in the spot pool | Not included. Both still show on the guess map |
| Spots near heiau, burial sites, or other wahi pana | Excluded during review (section 19) |
| Ground view in the daily | Off until the pool has 400 approved Ground spots |

## 5. Cheapest way to run it

Total cost to launch is the one time $25 Google Play developer fee. Monthly cost is $0 until the game is fairly popular.

| Piece | Service | Cost | Limit that matters |
|---|---|---|---|
| API | Cloudflare Workers free plan | $0 | 100,000 requests a day, 10 ms CPU per request |
| Database | Cloudflare D1 free | $0 | 5 million rows read and 100,000 rows written a day, resets at 00:00 UTC |
| Daily set job | Workers Cron Trigger | $0 | Included |
| Guess map tiles | OpenFreeMap | $0 | No key, no limits. Add a donate link in About |
| Sky imagery, sharp | Esri World Imagery via ArcGIS Location Platform | $0 | 2 million tiles a month. If pay as you go stays off, Esri pauses the service instead of billing |
| Sky imagery, backup | USGS The National Map, USGSImageryOnly | $0 | Public domain, no key. Hawaiʻi imagery is older (NAIP 2013, about 1 meter) |
| Terrain for 3D | AWS Open Data Terrain Tiles (Terrarium) | $0 | No key. Confirm the URL still works before building |
| Ground imagery | Mapillary API and MapillaryJS | $0 | Free client token. Imagery is CC BY-SA, needs credit |
| Reminders | Local notifications on the phone | $0 | No server |
| Code and CI | GitHub public repo and Actions | $0 | Free for public repos |
| Practice pack updates | GitHub Pages JSON file | $0 | |
| Domain | Optional. `huli.<name>.workers.dev` is free | $0 to about $12 a year | |

Budget math per player per day
- API calls. 1 daily fetch, 5 round starts, 5 guesses, 2 leaderboard loads. About 13 requests. 100,000 divided by 13 is about **7,600 daily players** on the free plan.
- D1 writes. About 11 rows per player per day. About **9,000 daily players**.
- Esri tiles. Plan for about 300 tiles per daily play (5 rounds times about 60 tiles at 512 px). 2 million a month covers about **220 players a day**. This is the first limit you will hit. The app must switch to USGS imagery on its own when Esri returns a quota or auth error. Players should only notice slightly older imagery.

When it grows
1. Past 220 players a day. USGS backup kicks in on its own. Nothing to do.
2. Optional upgrade for sharp imagery at scale. A GitHub Action runs each night, downloads the USGS tiles for tomorrow's 5 spots, and puts them in Cloudflare R2 (free tier has free egress). This is fine because USGS imagery is public domain. Do not cache Esri tiles, their terms do not allow it.
3. Past about 7,000 players a day. Move to Workers Paid at $5 a month, which covers 10 million requests a month.

Why not other options
- Supabase free projects pause after a week without activity, which would break a small game.
- Firebase needs the paid Blaze plan for scheduled functions.
- Google Street View and Google satellite cost money past their free credit and their terms make an open source fork harder.

Tell Claude Code to log real tile counts per round in a debug panel so these numbers can be checked against real use.

## 6. Game rules

Daily challenge
- 5 rounds, same spots for everyone, new set at midnight HST.
- One try per player per day. Practice mode is unlimited.
- Round timer from `DAILY_ROUND_SECONDS` (default 120). When time runs out, the pin where it sits is locked in. No pin means 0 points.
- If the app closes mid round, the player can come back. The server knows when the round started. Remaining time keeps counting. A round that was started and never guessed scores 0 after its time plus 30 seconds.

Scoring (in `packages/shared/scoring.ts`, used by app and server, the server is the one that counts)
```
distance_km = haversine(guess, answer)
if distance_km <= 0.05: points = 5000
else: points = round(5000 * exp(-distance_km / SCORE_SCALE_KM))
SCORE_SCALE_KM = 25
```

| Distance | Points |
|---|---|
| 50 m or less | 5,000 (perfect) |
| 500 m | 4,901 |
| 1 km | 4,804 |
| 5 km | 4,094 |
| 10 km | 3,352 |
| 25 km | 1,839 |
| 50 km | 677 |
| 100 km | 92 |
| 150 km (wrong island) | 12 |

The right island matters most. Getting close on the right island is where the big points are.

Ties on the boards go to the faster total time, then to whoever finished first.

Streak is the number of Hawaiʻi days in a row with a finished daily.

## 7. The two views

### Sky view

- MapLibre map with a raster satellite source on top of a terrain source with `exaggeration` about 1.3. Mountains should look real. This is the wow moment of the app, so spend effort here.
- Camera starts at the spot's saved `zoom`, `pitch`, and `bearing`. Default zoom 16.5, pitch 55.
- Locked. No panning, no zooming. Set `minZoom` and `maxZoom` to the same value. Turn off drag pan, scroll zoom, box zoom, double click zoom, keyboard.
- Custom one finger swivel. Drag left and right changes bearing. Drag up and down changes pitch between 0 and 70. Add light momentum so it feels smooth. Two finger twist also rotates.
- Small compass button in the corner. Tap to face north again.
- No labels on the imagery.
- Imagery provider chain in `map/imagery.ts`
  1. Esri World Imagery if `VITE_ESRI_KEY` is set
  2. USGSImageryOnly if Esri fails with 401, 403, 498, 499, or quota errors, or if no key
  Remember the switch for the rest of the day so it does not flip back and forth.
- Credit line on screen, small, bottom left, for whichever provider is showing.

### Ground view

- MapillaryJS viewer showing one 360 panorama by image id.
- Turn off every way to move. Deactivate the sequence, direction, spatial, and keyboard components. Keep drag to look around and a small zoom in.
- Hide anything that shows a date, place, or user name during the round. Show "Imagery © Mapillary contributors, CC BY-SA" on screen during the round, and the photographer's user name with a link on the reveal screen.
- Only panoramas (`is_pano = true`).
- Destroy the viewer when leaving the round so only one WebGL view is alive at a time.

## 8. The guess map

- Bottom sheet over the view. A floating "Guess" button opens it to half height. Drag up for full screen.
- MapLibre with an OpenFreeMap vector style, restyled to match the app colors. Place names come from OSM, which often has the ʻokina. Prefer `name:haw` when present if the "Hawaiian place names" setting is on.
- Starts framed on all main islands. `maxBounds` roughly west 160.6, south 18.7, east 154.6, north 22.4 (all W and N). Zoom range 5.5 to 17.
- Tap to drop the pin. Tap again to move it. Drag the pin to fine tune.
- "Lock in guess" button is disabled until a pin is down.
- Light haptic when the pin drops.

## 10. Tutorial and practice

Short tutorial, 4 swipe cards, each one sentence plus a looping illustration
1. "You get 5 places in Hawaiʻi each day."
2. "Drag to turn and look around. You can't move, so look closely."
3. "Open the map and drop your pin where you think you are."
4. "The closer you are, the more points. Up to 5,000 a round."

Tutorial mode is a guided first round at an easy spot (Lēʻahi works well). Coach marks point at each control in order and wait for the player to do it. Swivel, open the map, drop a pin, lock in, see the reveal. No timer, no score saved. Can be replayed from Settings.

Practice mode
- Endless rounds, not on the leaderboard, timer off by default.
- Uses `practice-pack.json` bundled in the app (start with 300 spots, all retired from the daily or practice only). The app checks GitHub Pages once a week for a newer pack. This costs nothing on the backend.
- Optional hint button. First hint shows the island outline.
- Filters for island and view type.

## 14. Names and the swear filter

Rules in `packages/shared/names.ts`, used by both app and server.
- 3 to 18 characters after trimming.
- Letters including ā ē ī ō ū and other common accented letters, digits, spaces, and ʻ ' . _ -
- Normalize to NFC. Collapse repeated spaces.
- For uniqueness, compare a key that is lowercased, with ʻ (U+02BB), ‘ (U+2018), and ' treated as the same mark.
- Block names that pretend to be staff, like admin, moderator, official, huli team.
- Swear filter with the `obscenity` package, English dataset plus its recommended transformers so tricks like l33t speak, spacing, and repeated letters are caught.
- Add `blocklist.extra.txt` and `allowlist.txt` in `packages/shared` for local words Olin wants to add or allow.
- Test file with at least 200 Hawaiʻi place names and common Hawaiian words that must all pass the filter. This stops false blocks.
- Friendly error copy. "That name isn't allowed. Try another one." and "That name is taken."
- Reports. 3 reports hide a name from boards until Olin reviews it. Hidden players show as "Player 4821".

## 16. API

Base path `/v1`. JSON. Auth is `Authorization: Bearer <token>` except where noted. All inputs checked with Zod.

| Method and path | Auth | What it does |
|---|---|---|
| `POST /players` | none | Body `{ name }`. Creates a player. Returns `{ playerId, token, name }`. Token is 32 random bytes, only its SHA-256 hash is stored |
| `PATCH /players/me` | yes | Change name |
| `DELETE /players/me` | yes | Deletes the player and all their plays |
| `GET /daily` | yes | Returns `{ date, rounds: [{ index, mode }], timerSeconds, progress }`. No coordinates |
| `POST /daily/rounds/:i/start` | yes | Records start time once. Returns what the view needs. Sky gives `{ lat, lon, zoom, pitch, bearing }`. Ground gives `{ imageId }` |
| `POST /daily/rounds/:i/guess` | yes | Body `{ lat, lon }` or `{ timeout: true }`. Server scores it. Returns `{ points, distanceM, answer: { lat, lon, placeName, island, funFact, credit } }` |
| `GET /leaderboard/day?date=YYYY-MM-DD` | yes | Top 50 plus your row |
| `GET /leaderboard/month?month=YYYY-MM` | yes | Top 5 plus your row |
| `POST /players/:id/report` | yes | Report a name, once per reporter |
| `GET /health` | none | For uptime checks |
| `/admin/*` | `ADMIN_TOKEN` | Hide or unhide a player, rename, list reports, manage spots |

Round rules on the server
- A round can only start after the one before it has a guess.
- A guess is only accepted once, and only within timer plus 30 seconds of start.
- Simple rate limit per token and per IP using a small D1 table or the Workers rate limit binding.

## 17. Database (D1)

```sql
CREATE TABLE players (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  name_key TEXT NOT NULL UNIQUE,
  token_hash TEXT NOT NULL UNIQUE,
  hidden INTEGER NOT NULL DEFAULT 0,
  reports INTEGER NOT NULL DEFAULT 0,
  created_at INTEGER NOT NULL
);

CREATE TABLE locations (
  id INTEGER PRIMARY KEY,
  mode TEXT NOT NULL CHECK (mode IN ('sky','ground')),
  lat REAL NOT NULL,
  lon REAL NOT NULL,
  island TEXT NOT NULL,
  place_name TEXT NOT NULL,
  zoom REAL, pitch REAL, bearing REAL,
  image_id TEXT,
  credit TEXT,
  fun_fact TEXT,
  difficulty INTEGER NOT NULL CHECK (difficulty BETWEEN 1 AND 5),
  status TEXT NOT NULL DEFAULT 'candidate',
  last_used TEXT,
  notes TEXT
);

CREATE TABLE daily (
  date TEXT NOT NULL,
  round INTEGER NOT NULL,
  location_id INTEGER NOT NULL REFERENCES locations(id),
  PRIMARY KEY (date, round)
);

CREATE TABLE plays (
  player_id TEXT NOT NULL REFERENCES players(id) ON DELETE CASCADE,
  date TEXT NOT NULL,
  round INTEGER NOT NULL,
  started_at INTEGER NOT NULL,
  guessed_at INTEGER,
  guess_lat REAL, guess_lon REAL,
  distance_m INTEGER,
  points INTEGER,
  PRIMARY KEY (player_id, date, round)
);

CREATE TABLE day_totals (
  player_id TEXT NOT NULL REFERENCES players(id) ON DELETE CASCADE,
  date TEXT NOT NULL,
  month TEXT NOT NULL,
  total INTEGER NOT NULL,
  total_ms INTEGER NOT NULL,
  finished_at INTEGER NOT NULL,
  PRIMARY KEY (player_id, date)
);
CREATE INDEX day_rank ON day_totals (date, total DESC, total_ms ASC);
CREATE INDEX month_rank ON day_totals (month, total DESC);

CREATE TABLE reports (
  reporter_id TEXT NOT NULL,
  player_id TEXT NOT NULL,
  created_at INTEGER NOT NULL,
  PRIMARY KEY (reporter_id, player_id)
);

CREATE TABLE settings (key TEXT PRIMARY KEY, value TEXT NOT NULL);
```

Settings table holds `DAILY_MODES` (example `["sky","sky","sky","sky","sky"]`), `DAILY_ROUND_SECONDS`, `MONTH_RANK_MODE`, `SCORE_SCALE_KM`.

## 18. Making each day's 5 spots

- Cron Trigger runs at 10:05 UTC (12:05 AM HST) and keeps 7 days filled ahead.
- Picks are seeded with HMAC of the date using a secret `DAILY_SEED_SECRET`, so future days cannot be guessed from the open source code.
- Rules
  - Only `approved` spots not used in the last 365 days.
  - At least 3 different islands each day, no more than 2 from one island.
  - Oʻahu can be in the set but not every round, so neighbor islands get love.
  - Difficulty goes up across the day. Round 1 is easy (1 or 2), round 5 is hard (4 or 5).
  - Mode per round comes from `DAILY_MODES`.
- Writes `daily` rows and sets `last_used`.
- If the pool runs low (under 120 days of fresh spots), log a warning on `/admin/health`.

## 19. Building the spot pool

Goal is 2,500 approved spots so nothing repeats within a year.

Sky candidates (`tools/pool-builder/sky.ts`)
1. Download the Hawaiʻi OSM extract from Geofabrik.
2. Sample random points on land on each island. Weight by island so the mix feels fair, not only by land area.
3. Keep points within a set distance of a road, building, trail, beach, or landmark, so most spots have something to look at. Keep about 15% fully wild for hard rounds.
4. Get the nearest place name from the OSM data (offline, no API calls).
5. Suggest a starting bearing that faces the most interesting direction (toward the coast or the mountain).
6. Drop spots that are mostly ocean, mostly cloud, or on Niʻihau or Kahoʻolawe (unless Olin turns them on).

Ground candidates (`tools/pool-builder/ground.ts`)
1. Use the Mapillary coverage vector tiles to find 360 panoramas on each island.
2. Keep at most one panorama per 2 km so spots spread out.
3. Prefer recent captures and higher quality scores.
4. Print a count per island so we know where coverage is thin.

Review tool (`tools/review`)
- Local web page that shows each candidate exactly as a player would see it.
- Keyboard keys to approve, reject, set difficulty 1 to 5, edit bearing, add a fun fact.
- Reject spots that show a private home up close, people's faces in Ground view, heiau, burial sites, or other wahi pana. When in doubt, reject.
- Writes results to D1 through the admin API.

## 20. Cheating, honestly

The app is open source and the view needs real coordinates, so a determined cheater can always find the answer. The goal is to make cheating annoying and keep the boards clean, not to be perfect.
- The server scores every guess. The app never sends points.
- Each spot is only sent when its round starts, one round at a time.
- One try per day, enforced by the server.
- Flag days where all 5 rounds are near perfect and each took under 8 seconds. Flagged days do not show on boards until reviewed.
- Reports and hide tools in the admin API.

## 21. Design

Look and feel. The imagery is the hero. Everything else stays quiet so the ʻāina carries the screen. One big moment, the reveal line drawing across the islands. No generic card grids, no gradients for decoration.

Colors

| Name | Hex | Use |
|---|---|---|
| Moana | #0B4F6C | Primary, buttons, guess map water |
| Kai pō | #0A1A24 | Dark mode background, night ocean |
| Kai kea | #EEF5F3 | Light mode background, sea glass |
| Lehua | #D7263D | Answer pin, wrong range, timer red |
| ʻIlima | #F2A900 | Your pin, score highlights, streak |
| Kalo | #3F7D3A | Good result color in share grid and stats |

Check every text and background pair for WCAG AA contrast in both themes.

Type
- Inter for all UI text. Inter is known to show the ʻokina (U+02BB) and kahakō vowels right on Android.
- A display face for big numbers and the app name only. Try Fraunces. Keep it only if a glyph test screen shows ʻ ā ē ī ō ū Ā Ē Ī Ō Ū perfectly. If not, use Inter Display at heavy weight.
- Tabular numbers for all scores and timers.
- Sentence case everywhere. No all caps labels.

Shape and motion
- Buttons are full pill shape. Sheets have a large top radius. Nothing else is rounded the same way.
- Motion only answers what the player did (sheet opens, pin drops, reveal). Reduced motion turns the reveal into a fade.

Sound and haptics
- 5 short sounds. Pin drop, lock in, point count tick, perfect round, day complete. Use CC0 sounds or make them. Keep them soft.
- Haptics on pin drop, lock in, perfect round.

App icon and splash
- Simple mark. A compass needle over the outline of the island chain. Adaptive icon with a themed monochrome layer for Android 13+.

## 22. Words in the app

- All copy lives in `i18n/strings.en.json`. No text hard coded in components.
- Plain words, short sentences, warm and local, never cute for its own sake.
- Island names always written correctly. Oʻahu, Hawaiʻi Island, Maui, Kauaʻi, Molokaʻi, Lānaʻi, Niʻihau, Kahoʻolawe.
- Use the ʻokina character U+02BB, never an apostrophe or a curly quote.
- Mark every Hawaiian word or phrase in the strings file with a `review: true` flag so a fluent speaker can check it before launch.
- Error copy says what happened and what to do. Example "No connection. Your round is saved. Try again when you're back online."

## 23. Quality floor

Accessibility
- TalkBack labels on every control. The guess map has an "Enter a place name" fallback that drops the pin on a typed place from the bundled OSM place list.
- Touch targets at least 48 dp.
- Color is never the only signal. Share grid and results also show numbers.
- Text scales with system font size.

Performance
- Cold start to Home under 2 seconds on a mid range phone.
- Only one WebGL view alive at a time.
- Pre load the next round's view while the reveal plays.
- Cache tiles on the phone (service worker or HTTP cache) and cap the cache size.
- Data saver turns off terrain and uses 256 px tiles.

Offline and errors
- If offline, Home says so and the Play button waits. A started round keeps its state and retries the guess when back online.
- Every network call has a retry with backoff and a clear message.

## 24. Privacy and Play Store

- No email, no login, no phone number, no ads, no tracking, no analytics SDKs.
- Never asks for location permission. The game does not need it.
- Stored on the server: player name, random id, token hash, guesses, scores, report counts.
- In app delete removes all of it.
- Play Data safety form. App activity (scores) and user IDs (app made), not shared, sent over HTTPS, delete available in app.
- Content rating Everyone.
- Target the API level the Play Store requires at release time.
- Short privacy policy page on GitHub Pages, linked from Settings and the store listing.
